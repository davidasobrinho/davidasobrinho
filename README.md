### Hi, I'm David 👋

Product Manager in Porto, working on AI inside complex B2B platforms. This is where I build hands-on: apps, agents, and the skills and eval loops behind them.

**How I build**

- **Context first.** A private, version-controlled knowledge base that every agent reads before it starts, so my agents never need re-explaining.
- **One repo per product, tool-agnostic.** Each repo has an `AGENTS.md`, so Claude Code, Codex, Cursor or Gemini CLI can all work on it. Skills follow the open Agent Skills format and data reaches agents through MCP.
- **The right host for each job.** Cloudflare for sites, light APIs and scheduled jobs. Firebase when an app needs accounts, sync and offline.
- **Evals are the product.** Every agent decision is logged with its reason, every correction becomes a rule at the cheapest stage, and no change ships without a test.
